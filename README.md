# deepseek-harness-desktop

[English](README_EN.md)

`deepseek-harness-desktop` 是官方 DeepSeek Harness Web UI 的轻量桌面启动器，不保存任何信息，会辅助检查deepseek-harness更新。

## 开发

需要 Node.js 和 npm。

```powershell
npm install
npm run dev
```

```powershell
npm run dev:debug
npm run typecheck
npm run build
npm run package:win
```

# deepseek-harness-desktop

[中文](README.md)

`deepseek-harness-desktop` is a lightweight desktop launcher for the official DeepSeek Harness Web UI.

## Development

Node.js and npm are required.

```powershell
npm install
npm run dev
```

```powershell
npm run dev:debug
npm run typecheck
npm run build
npm run package:win
```
